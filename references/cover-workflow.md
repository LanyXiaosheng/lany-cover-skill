# 封面提炼与提示词

## 内容提炼

从完整材料中只保留：准确标题、必要副标题、一个主体动作、一个物理关系、受众与用途。先确定本次视觉重点；题目里有“省钱”“增长”等结果词时，没有真实数据就用抽象关系，不画伪证据。

中文主标题优先控制在 6—14 个字并最多两行。原题较长时可拆成两层，例如主标题“REA邪修，”与副标题“AI不能立马赚钱，但能立马省钱”；拼回去必须与用户原题逐字一致，不能把原文省略成虚构承诺。

需要专门设计中文字形或字效时，可用 `$lany-typography-prompts` 生成标题文字提示词；完整画面的主体关系、人物与画幅仍由封面 Skill 决定。最终逐字核对中文，生图错字时用可编辑文字层修正。

## 紧凑提示词骨架

不要逐段粘贴品牌文档。将下面字段压缩成一份紧凑提示词，并把实际风格与参考图路径写进保存的提示词文件：

```text
用途与比例：一张 {平台} 封面，{比例}。
内容：主标题逐字为“{标题}”；副标题逐字为“{副标题或无}”。
主体关系：小生在 {位置和动作}，通过 {一个有内容依据的视觉关系} 表达主题。
构图：{针对比例的非对称布局与安全区}。
身份：使用 {本轮唯一头像参考} 的同一小生，保留实际可见的脸型、发型、护目镜、耳机和服装轮廓；人物媒介为 {选定风格}，头像中不可见的细节不强行补齐。
视觉：使用 {选定风格的背景、标题颜色与强调色}；非对称编辑排版，一个核心视觉隐喻，充足留白，不做流程 PPT。
禁止：陌生脸、混合媒介、无关图标、随机文字、水印、二维码；所选媒介的具体禁用项见品牌系统。
```

## X 画幅

- X 长文或帖子封面：`5:2`，标题和人物分别占据清晰视觉区。
- X 主页背景由 `$lany-banner` 处理；不要把文章封面直接裁成主页 Banner。
- 不用裁切一张图去兼容多个比例；每个比例独立构图。

生成的源图比例与目标不符时，先目视判断标题、人物与核心关系是否落在目标 5:2 安全带内。裁切会切掉任何核心内容时重新生成；不能只凭尺寸脚本通过就交付。
