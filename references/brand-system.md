# Lany 小生品牌视觉系统

`../assets/lany-brand-reference.png` 只用于检查编辑构图、留白和技术结构，其中的平滑人物不是身份真源。人物媒介由本轮选定头像决定；默认只上传对应头像的一张轻量参考。

## 识别顺序

第一眼看见内容主题，第二眼认出小生与稳定的版式语言，第三眼理解一个核心关系。品牌一致性来自身份、层级与可复用的图形语言，不要求每张图使用同一背景。

## 颜色

- 默认深夜简报封面：哑光墨黑 `#0A0A0A` 与石墨灰背景，暖白 `#F3F3ED` 标题，`#D8FF00` 用于一个受控信号或判断点；人物媒介默认自然手绘，不等于把头像改成像素。
- 自然手绘浅色封面：奶白 `#F6F3EB` 画布、墨黑 `#1C1C18` 标题与线条、雾蓝灰 `#DDE3E5` 少量衬底；`#D8FF00` 只点出一处关键连接或结果。
- 其他明确选中的媒介：从所选头像样例提取人物材质和色彩逻辑，再以稳定标题层级和少量 Lany 标识维持识别。头像的正方形背景不直接铺满横版封面。
- 蓝色只在参考头像可见的角色细节中保留，不作为第二主色。

## 小生角色

用户确认的头像优先于本文件的默认角色描述。若头像与下方描述冲突，以头像中实际可见的特征为准；下方只作为缺失细节的回退参考，不得强行套用。

- 保留参考图实际可见的少年感脸型、自然眉眼、黑色短发、头顶护目镜、颈挂银灰耳机和黑衣轮廓。
- 表情自然、专注；不要靠放大眼睛、尖下巴、腮红或高光改变身份。
- 胸前白色 `小生` 字标、裤鞋等不可见细节不强制补齐。蓝色标记仅在参考图有依据且画幅可见时保留。
- 像素参考保留阶梯边缘，手绘参考保留自然墨线，三维参考保留其材质；不同媒介不混成一个角色。

## 构图语言

- 使用非对称编辑构图、大面积呼吸空间、少量细线或几何切面，清楚分出标题与人物区域。
- 每张图只保留一个视觉隐喻或一个工作关系。信号线、节点或卡片只在真正解释主题时出现，不强制加入。
- 封面像一页有判断的编辑作品，不是流程 PPT；人物可以参与动作，也可以作为辨识锚点，但不能压过主题。
- 标题跟随选定媒介但必须准确、完整、远看可读：像素版可使用克制的方块边缘，手绘版可保留少量墨笔触感；副标题和信息标签保持清晰常规字形。文案最多三层。

## 禁止漂移

像素媒介只在明确选择或精修既有像素图时沿用，不将其他媒介硬转像素；用户明确选中三维、黏土、写真或日漫时可以使用，但必须保留小生身份，不把该试样自动升级为账号头像。所有风格都禁止陌生脸、杂乱 UI、随机文字、水印和未经要求的第三方品牌主色。
