# 封面人物风格路由

## 选择顺序

1. 本轮用户明确指定的头像图片、风格 ID 或已确认目标优先。图片既可能是身份参考也可能只是画风参考，先区分用途；用户自己的头像是身份真源。
2. 仅提到“用现在的头像”时，使用对话中最近明确选定的头像。没有可定位的目标才用本技能 `assets/lany-avatar-handdrawn-reference.png` 的自然手绘默认版；明确要精修既有像素封面时仍保留原媒介。
3. 用户按编号或 ID 选人物风格时，按需读本技能 [头像媒介目录](avatar-styles.md) 的对应条目；选封面语言时读 [封面语言目录](cover-languages.md) 对应条目。人物样例只确定媒介，不固定其动作、表情、身份或方形背景。样例文件缺失时，请用户提供参考图，不能暗自换回像素版。
4. 一次默认交付一种风格的一张图。明确要求比较多种风格时，每种独立提示词、独立生成与校验，不做混合媒介拼贴，也不因生成成功而更改全局默认头像。

## 四个必需信息，两个可选信息

| 输入 | 作用 | 缺失时 |
| --- | --- | --- |
| 头像参考 | 决定是谁 | 用本轮已确认头像，否则内置自然手绘参考 |
| 人物风格 | 决定怎么画小生 | 跟随头像媒介，未指定时为 `soft-handdrawn`；像素须明确选中 |
| 标题或文章 | 决定说什么 | 没有主题材料才询问 |
| 封面语言 | 决定页面怎么组织 | 普通任务用 `night-brief`；请求挑选时推荐三种并等待选择 |
| 平台与比例 | 决定画幅 | 能从上下文判断就沿用，仍不明才询问平台 |
| 视觉重点 | 决定先看哪里 | 按标题与文章判断，不编造结果 |

人物风格与封面语言是两个不同的“风格”。给用户展示选项时使用中文名并附 ID，不把两者混成一张固定模板。用户只给部分字段时使用已确认的上下文和默认值，不要求重复填写。

## 三个视觉变量

| 变量 | 决定什么 | 例子 |
| --- | --- | --- |
| 头像媒介 | 人物的画法和材质 | 像素、自然手绘、丝印、赛璐璐、立体、毛绒 |
| 封面语言 | 画面的版式、底色和材料 | 深色报告、浅色杂志、纸张拼贴、高对比印刷、极简画册 |
| 视觉重点 | 读者第一眼看到的内容 | 标题、人物、过程、结果、真实产品 |

用户只选一个变量时，其余沿用该任务中已确认的条件；不要把“像素头像”自动等同于“黑底封面”，也不要把“手绘头像”自动等同于“浅色封面”。混搭测试固定同一标题与主题；如果目的是比较封面语言，尽量固定头像媒介；如果目的是探索组合，可交叉搭配并在结果中标明。同一张图只用一种小生媒介；明确选三格分镜时允许同一小生跨格重复，但不能混成不同身份。

## 可用参考

| 选择 | 封面人物参考 | 封面视觉 |
| --- | --- | --- |
| 未指定 / `soft-handdrawn` | `../assets/lany-avatar-handdrawn-reference.png`（相对本 reference） | 默认 `night-brief`；用户可另选浅色语言 |
| 明确选择 `pixel` | `../assets/lany-avatar-reference.png` | 兼容旧像素媒介，不进入默认推荐 |
| 其他目录风格 | `../assets/styles/<style-id>.png`，按目录核实实际文件名 | 封面语言单独选择，不照搬头像方形背景 |
| 本轮上传头像 | 本轮明确指定的图片 | 身份以图片为准，配色按用户要求与内容用途决定 |

表中路径以本技能 `references/` 为基准。所有目录参考随本技能打包，用户本次提供的头像仍是身份真源。写真试样是虚构角色真人化，不能写成用户本人照片；毛绒/潮玩只是视觉概念。
