# 封面人物风格路由

## 选择顺序

1. 本轮用户明确指定的头像图片、风格 ID 或已确认目标优先。图片既可能是身份参考也可能只是画风参考，先区分用途；用户自己的头像是身份真源。
2. 仅提到“用现在的头像”时，使用对话中最近明确选定的头像。没有可定位的目标才用本技能 `assets/lany-avatar-reference.png` 的像素默认版。
3. 用户按编号或 ID 选风格时，按需读本技能 [头像媒介目录](avatar-styles.md) 的对应条目。风格样例只确定媒介，不固定其动作、表情、身份或方形背景。样例文件缺失时，请用户提供参考图，不能暗自换回像素版。
4. 一次默认交付一种风格的一张图。明确要求比较多种风格时，每种独立提示词、独立生成与校验，不做混合媒介拼贴，也不因生成成功而更改全局默认头像。

## 三个独立选择

| 变量 | 决定什么 | 例子 |
| --- | --- | --- |
| 头像媒介 | 人物的画法和材质 | 像素、自然手绘、丝印、赛璐璐、立体、毛绒 |
| 封面语言 | 画面的版式、底色和材料 | 深色报告、浅色杂志、纸张拼贴、高对比印刷、极简画册 |
| 视觉重点 | 读者第一眼看到的内容 | 标题、人物、过程、结果、真实产品 |

用户只选一个变量时，其余沿用该任务中已确认的条件；不要把“像素头像”自动等同于“黑底封面”，也不要把“手绘头像”自动等同于“浅色封面”。混搭测试固定同一标题与主题，通常挑 4—6 组有实质差异的组合；每张图仍只出现同一位小生的一种媒介，不做拼贴式多个人物。

## 可用参考

| 选择 | 封面人物参考 | 封面视觉 |
| --- | --- | --- |
| 未指定 / `pixel` | `../assets/lany-avatar-reference.png`（相对本 reference） | 默认深色报告；用户可另选封面语言 |
| `soft-handdrawn` | `../assets/lany-avatar-handdrawn-reference.png` | 默认奶白纸面；用户可另选深色报告等语言 |
| 其他目录风格 | `../assets/styles/<style-id>.png`，按目录核实实际文件名 | 封面语言单独选择，不照搬头像方形背景 |
| 本轮上传头像 | 本轮明确指定的图片 | 身份以图片为准，配色按用户要求与内容用途决定 |

表中路径以本技能 `references/` 为基准。所有目录参考随本技能打包，用户本次提供的头像仍是身份真源。写真试样是虚构角色真人化，不能写成用户本人照片；毛绒/潮玩只是视觉概念。
