# Lany 封面语言目录

这里的封面语言只决定页面的构图、材料和标题行为，**不决定小生头像媒介**。每张封面只用一种语言；与人物风格交叉搭配时，保留用户选定头像中可见的身份特征。标题、平台和内容优先于样张。编号仅供选择，不代表质量排名。以下是为小生独立编写的视觉方向，不复用第三方仓库的风格规格或图像。[33 种语言的非像素出图与状态](../examples/rea-nonpixel-33/index.md)可按图对照。

| ID | 中文名 | 页面规则与主要避项 |
| --- | --- | --- |
| `cream-fold` | 奶白折页 | 浅色纸面与一条折线组织标题和人物；避免把抽象折线画成数据图。 |
| `night-brief` | 深夜简报 | 炭黑底、克制黄绿判断点、明确左右信息层级；避免仪表盘。 |
| `layered-notes` | 批注拼版 | 少量纸片、手写批注和人物动作形成一组关系；避免碎片泛滥。 |
| `impact-ink` | 粗墨冲击 | 大块黑白油墨与受控颗粒强调一句判断；避免脏脸和过量噪声。 |
| `object-gallery` | 单物画册 | 中性展台、单一物件与大留白；避免无意义的奢侈质感。 |
| `warm-marker` | 手记结果 | 温暖纸面、几笔手绘标记指向结果；避免额外小字。 |
| `letter-stream` | 字流穿行 | 标题字形化为画面动线，人物从字与字之间穿过；文字仍须完整可读。 |
| `paper-portal` | 纸门捷径 | 一道层叠纸门从繁复空间通向简洁空间；避免纸层遮挡标题。 |
| `charcoal-clear` | 炭笔擦亮 | 黑白炭笔中一处被擦亮的清晰路径；避免复古版画仿制。 |
| `analog-counter` | 模拟工作台 | 机械滚轮、空白标签与手工装置表达少走一步；避免伪造账单。 |
| `glass-layers` | 透光层叠 | 磨砂透明板让冗余步骤退到后景；避免软件 HUD 和假界面。 |
| `archive-sleeves` | 档案袋 | 空白文件套与整齐归档形成“减负”隐喻；避免真实票据或商标。 |
| `signal-ribbon` | 信号缎带 | 一根连续色带从绕路变为直达；避免画成真实趋势曲线。 |
| `copper-lines` | 铜线通路 | 稀疏金属线把重复回路接成短路径；避免密集电路板。 |
| `chalk-sequence` | 粉笔推演 | 黑板上的几步线条被简化，人物执行最后一步；不写伪公式。 |
| `clay-panels` | 陶土薄片 | 有手作纹理的片状结构从厚变薄；避免婴儿玩具气质。 |
| `negative-film` | 负片显影 | 负片边框中一格亮出清晰解法；避免电影品牌和真实截图。 |
| `woven-paths` | 编织路径 | 两种纤维交织，冗余线头被收拢；避免复杂花纹吞没标题。 |
| `folded-route` | 折叠路线 | 把绕远的纸质路线折成一条短路；不是地理地图或导航截图。 |
| `modular-board` | 可拆模块 | 小方块搭出工作流，人物拿掉多余一块；避免游戏 HUD。 |
| `shadow-stage` | 影子剧场 | 聚光灯把冗长影子缩成简洁动作；避免陌生人剪影。 |
| `ink-breath` | 墨迹留白 | 稀疏墨迹与一处留白表现取舍；避免套用传统题字模板。 |
| `electric-sign` | 电光字牌 | 低亮度灯管只照亮关键词，人物仍是识别锚点；避免赛博城市背景。 |
| `technical-cutaway` | 结构剖面 | 一个虚构物件的简单剖面揭示省去的夹层；避免冒充真实产品结构。 |
| `sunrise-gradient` | 晨光渐层 | 大面积柔和晨光中一条干净路径浮现；避免俗套励志剪影。 |
| `sticker-board` | 贴纸工作板 | 大小不同的形状贴片被重新排序；避免手账装饰堆砌。 |
| `metal-press` | 金属压印 | 冷灰压印板与一道浅浮雕形成清晰判断；避免品牌徽章仿品。 |
| `prismatic-card` | 棱镜卡片 | 一张半透明卡把冗杂折射成单一路径；避免炫光盖住中文。 |
| `isometric-room` | 俯视小房间 | 从上方看小生把桌面步骤收拢；避免像流程图或手游。 |
| `comic-triptych` | 三格转折 | 三个简洁画格展示繁杂、发现、简化；标题必须独立完整。 |
| `branch-pruning` | 修枝生长 | 一根抽象枝条剪去无效分叉；避免暗示真实增长数据。 |
| `architectural-threshold` | 空间门廊 | 一处门槛连接拥挤与开阔空间，人物跨过它；避免室内装修广告感。 |
| `orbital-shortcut` | 轨道捷径 | 几条简洁圆弧中出现一条更短的连接；避免宇宙游戏 HUD。 |

选择时先看内容隐喻是否适合，再看头像媒介能否在该材料里保留身份。若只想快速做一张，推荐三个有明显差异的语言供用户选择，或在用户要求自动决定时选一种；明确要求全量测试时逐个独立出图、记录失败与实测状态，不把候选自动设为默认。

## 实测后补充的定向约束

- `letter-stream`：大标题容易贴边；在提示词里明确整块文字的安全框，不以加大字形代替动势。涉及“省钱”也不要让模型自动加入硬币、存钱罐或钞票。
- `sticker-board`：容易变成“人物→机器人→齿轮”的图标流程。只用抽象贴片和一个可见的移除动作，不做图标链。
- `isometric-room`：容易变成大头像加桌面。必须让房间本身成为主视觉，写明高角度、完整小房间和占画面较小的人物；否则标为未达风格目标。
