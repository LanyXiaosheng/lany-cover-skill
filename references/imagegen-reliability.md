# 生图可靠性与失败处理

## 输入

- 先确认当前环境有可用生图工具；不通过访问本地代理或私有接口推断工具状态。
- 每张图默认使用本轮选定的一张人物参考。用户提供的身份图片优先；目录样例是媒介参考，不自动替代用户身份。
- 需要上传轻量副本时用 `scripts/prepare_reference.py` 缩至最长边约 384 px，保留原图。若两张参考确实分别承担“身份”和“媒介”且工具支持，可明确标注用途后同时传入；不要让媒介样例覆盖身份。
- 提示词只保留主题、逐字标题、人物、版式、媒介和禁用项，不粘贴整篇文章或风格文档。

## 失败与验收

1. 区分工具不可用、网络/上传失败、生成失败、成图质量失败；只对可重试故障重试，单张最多三次。
2. 参考图上传失败时先核查文件能否读取、格式与体积；可再试轻量副本，不静默去掉身份参考。
3. 成图后立即记录工具返回的实际文件路径。无法保存或查看时如实报告，不把提示词当成已生成图片。
4. 自动脚本只检查尺寸及简单的背景特征；中文字、角色身份、主体关系和裁切安全区必须目视确认。
5. 正式图与生成源图分开保存；同名输出加版本号，不覆盖用户已有文件。
